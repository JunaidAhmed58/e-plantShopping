# Paradise Nursery

Paradise Nursery is an e-commerce React application that allows users to browse plants, view plant details, and manage their shopping cart.

## Features
- Interactive landing page with "Get Started" button
- Product listing displaying available plants with categories and prices
- Shopping cart with functionality to add, remove, and update plant quantities
- Total cost calculation dynamically updating based on cart actions

## Project Structure
- `src/App.jsx`: Main application routing and landing page
- `src/ProductList.jsx`: Displays available plants
- `src/CartItem.jsx`: Shopping cart component
- `src/CartSlice.jsx`: Redux slice managing cart state
- `src/AboutUs.jsx`: Information about Paradise Nursery
